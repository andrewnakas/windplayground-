# windplayground — global wind forecasting with ML

CPU-scale recreations of the top global ML weather models (GraphCast, Stormer,
FourCastNet lineages), trained on 5.625° ERA5 and evaluated WeatherBench-style on wind
variables — plus learned post-processing that targets beating the published GraphCast/HRES
forecasts on 2020 wind metrics at that resolution.

- **`REPORT.md`** — literature review: top papers, entities, and benchmarks.
- **`RESULTS.md`** — results tables and figures (generated by `scripts/make_report.py`).

## Quickstart

```bash
uv venv .venv
uv pip install --python .venv/bin/python torch --index-url https://download.pytorch.org/whl/cpu
uv pip install --python .venv/bin/python -e ".[dev]"

.venv/bin/python -m pytest                          # unit tests
.venv/bin/python scripts/build_cache.py             # ~4 GB ERA5 cache (resumable)
.venv/bin/python scripts/evaluate.py --model persistence
.venv/bin/python scripts/train.py --config configs/unet.yaml
.venv/bin/python scripts/evaluate.py --ckpt artifacts/checkpoints/unet/best.pt
```

GPU note (GTX 10-series/Pascal): install a torch build with `sm_61` kernels —
`cu118`/`cu126` wheels of torch ≤ 2.6 (`cu128+` dropped Pascal). Training code is
device-agnostic (`--device auto|cpu|cuda`), fp32 by default.
